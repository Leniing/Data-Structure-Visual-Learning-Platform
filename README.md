# 数据结构可视化学习平台

在交互画布上学习 C / C++ 数据结构。拖动画布、单步播放，对照高亮代码观察链表的指针更新和二叉搜索树的查找路径。

## 快速开始

按以下 10 分钟复现清单，可在本地启动并体验两个实验。

### 1. 配置环境并克隆仓库

安装 Git、Node.js 22.12+（含 npm）并准备现代浏览器。打开终端执行：

```bash
git clone https://github.com/Leniing/Data-Structure-Visual-Learning-Platform.git
cd Data-Structure-Visual-Learning-Platform
```

### 2. 安装依赖并打开网页

在项目根目录执行：

```bash
npm ci
npm run dev
```

保持终端运行，在浏览器打开终端显示的 **Local** 地址，通常为 `http://localhost:5173/`。Windows PowerShell 若提示禁止运行 `npm.ps1`，可将命令中的 `npm` 改为 `npm.cmd`。

依赖清单见 [package.json](package.json)，安装版本由 [package-lock.json](package-lock.json) 锁定。

## 项目特性

- **可交互的过程演示**。画布用 SVG 展示节点、连线、指针和查找路径。可平移、缩放，并在支持的状态下拖动节点，以便查看结构细节。
- **画布与代码同步**。动画和代码高亮读取同一个步骤状态，暂停后可以逐步前进或回退，观察某次指针更新或节点比较对应的语句。
- **学习前先预览**。已开放知识点的卡片带有悬停动画。可以先在总览看简短过程，再进入完整演示。
- **在当前知识点提问**。AI 助教以浮窗叠加在学习界面上，发送时附带教学页面与语言上下文，便于边对照动画边追问。

## 使用指南

### 侧边栏导航

| 入口 | 功能与常用操作 |
| --- | --- |
| 学习总览 | 查看知识卡片，按名称或关键词搜索，按类别筛选。在已开放卡片上悬停预览，点击「开始学习」进入页面。 |
| 本章知识 | 打开当前章节的知识点目录。点击已开放条目进入学习页。 |
| AI 解答 | 打开助教浮窗。输入问题后点发送或按 Enter，Shift + Enter 换行。可拖动标题栏移动窗口，通过边角调整大小。 |
| 练习挑战 | 预留入口，当前版本点击会提示「功能暂未开放」。 |
| 设置 | 切换浅色、深色或跟随系统，调整配色、界面字体及教学代码字体。更改即时生效，可恢复默认，再点「返回学习」。 |

### 学习页面操作

| 界面 | 常用操作 |
| --- | --- |
| 单链表创建 | 第一行输入节点数（0～12），第二行输入对应数量的整数（-999～999，用空格分隔）。在画布选择「头插法」或「尾插法」并创建，切换 C / C++ 查看教学代码。暂停或结束时可拖动节点和指针。 |
| 二叉搜索树查找 | 在预设树中输入一个 32 位有符号整数，点「开始查找」。切换「递归 / 非递归」对照访问顺序和返回过程，观察命中或未命中结果。画布中的节点与 NULL 标记可以独立拖动。 |
| 两个学习页面通用 | 拖动画布空白处平移，用「＋」「－」调整缩放。播放区提供暂停、继续、上一步、下一步、重播和重置，可选择 0.5×、1×、2× 或 4×。 |

## AI 助教

项目已实现「AI 解答」浮窗及 DeepSeek 服务端接入，当前提交版提供源码和[环境变量模板](.env.server.example)。

> 当前版本未提供在线助教服务及 API 凭据。AI 回复需要另行配置服务端凭据，动画实验可独立运行。

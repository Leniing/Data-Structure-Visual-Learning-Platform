# 数据结构可视化学习平台

基于 React、TypeScript 和 Vite 的数据结构学习平台。当前仅包含最小启动页面，实验功能尚未实现。

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm

## 安装与启动

```bash
npm install
npm run dev
```

在终端显示的本地地址打开页面。

## 检查命令

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

目前尚无测试用例；`npm test` 会运行 Vitest 并报告无匹配测试文件。

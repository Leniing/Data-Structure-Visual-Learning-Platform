# 数据结构可视化学习平台

基于 React、TypeScript 和 Vite 的数据结构学习平台。当前仅包含最小启动页面，实验功能尚未实现。

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm

## 安装与启动

```bash
npm install
npm run dev
```

在终端显示的本地地址打开页面。

## 页面布局

桌面端（宽度大于 760px、高度至少 640px）按浏览器可视高度展示一页，链表画布与教学代码按 65:35 分配可用宽度。切换创建方式不会改变面板尺寸；代码超出可用空间时在代码区内部滚动。小屏幕采用上下排列的固定高度面板，允许页面纵向滚动；高度不足 640px 的桌面窗口也允许页面滚动，避免挤压内容。

画布使用固定演示数据 5、7、4，尚未连接表单输入或算法播放。每个节点包含间隔分开的数据域和指针域，拖动任一部分会整体移动该节点，其他节点保持原位；head 和 NULL 使用相同的紧凑透明占位区域（60 × 32），均可独立拖动，连接线按方向落在透明区域边缘。直线箭头始终连接前一节点的指针域与下一节点的数据域，箭头采用开放的手绘风格线条。拖动空白区域平移画布，滚轮缩放范围为 60%–180%。

# 数据结构可视化学习平台

基于 React、TypeScript 和 Vite 的数据结构学习平台。目前支持无头结点的 C / C++ 头插法与尾插法创建动画，以及二叉搜索树递归 / 非递归查找。两种语言共用动画步骤，分别对应各自教学代码中的语句；两种语言的画布均用 NULL 表示空指针。

## 二叉搜索树查找（2026-11-17）

访问 `/#bst-search`，或从本章知识 / 知识总览进入；支持直接访问与刷新。已开放知识点在总览、搜索、分类筛选及章节内优先展示，知识点 ID 和各状态组内部顺序不变。

- 预设树包含 14、7、18、5、11、25，全部 7 个空孩子以 NULL 文字呈现，保留 12 条结构连线。支持整体缩放和平移，节点位置固定。
- 输入范围为 -2147483648～2147483647；查找期间（含暂停）锁定目标，重置后可编辑。
- 切换查找方式重置演示，切换 C / C++ 保留步骤并映射教学行。教学文本在 `src/teaching/bstCode.ts`，动画纯函数在 `src/domain/bstSearch.ts`，教学文本不执行。
- 每步保存节点、连线、箭头、代码行和返回值。递归逐层返回完成后才显示结果；非递归在 break 时标绿，在 return root 时显示结果。隐藏查找页面时停止计时器推进。
- 默认节点及 NULL 使用主题变量；访问、成功、失败状态采用适配明暗模式的琥珀、绿色、红色，递归返回箭头为紫色。

本次验证：TypeScript、ESLint、生产构建与差异检查通过；23 个测试文件、132 项测试通过。覆盖两种算法的 11 / 25 / 17 / 14、输入边界、返回顺序及显示时机、不可变快照、逐步前进和回退、两种切换、页面计时器、双入口和刷新、稳定排序，以及原链表功能回归。

本机 npm 启动脚本指向缺失的 npm-cli.js，因此使用本地 Node 入口运行检查：`node node_modules/typescript/bin/tsc -b`、`node node_modules/eslint/bin/eslint.js .`、`node node_modules/vitest/vitest.mjs run`、`node node_modules/vite/bin/vite.js build`。

## 页面布局

桌面端（宽度大于 760px、高度至少 640px）按浏览器可视高度展示一页，链表画布与教学代码按 65:35 分配可用宽度。切换创建方式不会改变面板尺寸；代码超出可用空间时在代码区内部滚动。小屏幕采用上下排列的固定高度面板，允许页面纵向滚动；高度不足 640px 的桌面窗口也允许页面滚动，避免挤压内容。

初始画布为空。选择头插法或尾插法以及 C 或 C++，点击“创建链表”后逐步演示，结束时保留完整链表。每个节点的数据域和指针域共同移动；head、tail、NULL 使用紧凑透明区域（60 × 32），箭头按相对方向连接边缘。保持开放描边的直线箭头。暂停或完成后可独立拖动节点及指针；继续单步时恢复算法布局，避免手动位置影响创建过程。拖动空白区域平移画布，滚轮缩放范围为 60%–180%；长链表自动缩小以完整显示，可放大查看。

## 终端输入与创建动画

按两行输入，例如：

```text
4
5 7 4 3
```

- 第一行是节点个数 n，范围 0～12；第二行必须有恰好 n 个整数，用普通空格分隔（可连续多个空格），每个值为 -999～999。
- n = 0 时仍保留换行，第二行留空。默认输入为 `5` 和 `3 1 4 1 5`。
- 拒绝逗号、制表符、小数、非法字符、数量不符和越界值，不截断输入；输入总长度超过 160 个字符也会报错。
- 点击创建后自动播放，支持暂停、上一步、下一步、重播和 0.5×～4×速度。重置、编辑输入或切换方式/语言会停止播放并清空画布。
- 画布与代码/输入区高亮共用不可变步骤快照。高亮 `scanf("%d", &n);` 时仅标出第一行 n 数字；高亮 `scanf("%d", &s->data);` 时仅标出第二行当前读取的数据值。输入文字始终保持可见。`head == NULL` 不成立和循环退出时显示红色；完成后清除高亮。
- `tail->next = s` 更新原尾节点的 next，`tail = s` 才移动 tail 本身。新节点依次经历分配空节点、读值、初始化 next、接入和归位。
- 教学 C / C++ 代码按用户提供的无头结点创建片段展示。C 使用 typedef、malloc、scanf 和 NULL；C++ 使用 struct、new、std::cin 和 NULL。不展示头文件、函数包裹、输入/分配失败检查或清理逻辑；这些片段不是独立可编译程序，不编译或执行。网页输入校验与 TypeScript 动画逻辑在教学面板之外，动画只演示正常输入、分配成功路径。scanf 与 std::cin 均按空白读取，网页两行格式校验更严格。
- 所有示例均没有头结点；head 指向首个数据节点，空链表时为空指针。头插法生成逆序链表，尾插法保持输入顺序。实际使用时需要释放节点：C 使用 free，C++ 使用 delete。

## 学习导航与浮窗

左侧保留 64px 导航空间，展开部分覆盖工作区，不改变画布尺寸。本章知识点击打开；学习总览和设置已开放，练习挑战仍提示“功能暂未开放”。

- 章节配置位于 `src/navigation/chapter.ts`，由页面传入 `LearningNavigation`。替换 `items` 中的标题、状态和 route 后，通过 `App.tsx` 的 `onSelectKnowledge` 接入实际演示状态；占位项保持 `placeholder`，不会跳转。
- 总览与本章知识均可进入单链表创建及二叉搜索树查找；总览搜索和分类筛选后仍优先展示已开放项。
- 导航延迟集中在 `src/navigation/timing.ts` 的 `navigationTiming`；浮层层级集中在 `navigation.css` 的 `--layer-*` 变量。
- AI 浮窗默认未接入服务，不发送请求、不生成演示回复。聊天适配器位于 `src/ai/`；未来通过服务端代理实现其 Promise 接口并启用配置，前端不保存密钥。关闭浮窗只隐藏，当前页面会话中的草稿与窗口位置保留。

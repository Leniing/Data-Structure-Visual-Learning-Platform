# 数据结构可视化学习平台

基于 React、TypeScript 和 Vite 的数据结构学习平台。目前支持无头结点的 C 语言尾插法创建动画；其他方式和语言保留只读教学代码。

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm

## 安装与启动

```bash
npm install
npm run dev
```

在终端显示的本地地址打开页面。

## 页面布局

桌面端（宽度大于 760px、高度至少 640px）按浏览器可视高度展示一页，链表画布与教学代码按 65:35 分配可用宽度。切换创建方式不会改变面板尺寸；代码超出可用空间时在代码区内部滚动。小屏幕采用上下排列的固定高度面板，允许页面纵向滚动；高度不足 640px 的桌面窗口也允许页面滚动，避免挤压内容。

初始画布为空。选择“尾插法 + C”，点击“创建链表”后逐步演示，结束时保留完整链表。每个节点的数据域和指针域共同移动；head、tail、NULL 使用紧凑透明区域（60 × 32），箭头按相对方向连接边缘。保持开放描边的直线箭头。暂停或完成后可独立拖动节点及指针；继续单步时恢复算法布局，避免手动位置影响创建过程。拖动空白区域平移画布，滚轮缩放范围为 60%–180%；长链表自动缩小以完整显示，可放大查看。

## 终端输入与创建动画

按两行输入，例如：

```text
4
5 7 4 3
```

- 第一行是节点个数 n，范围 0～12；第二行必须有恰好 n 个整数，用普通空格分隔（可连续多个空格），每个值为 -999～999。
- n = 0 时仍保留换行，第二行留空。默认输入为 `5` 和 `3 1 4 1 5`。
- 拒绝逗号、制表符、小数、非法字符、数量不符和越界值，不截断输入；输入总长度超过 160 个字符也会报错。
- 点击创建后自动播放，支持暂停、上一步、下一步、重播和 0.5×～4×速度。重置、编辑输入或切换方式/语言会停止播放并清空画布。
- 画布与高亮共用不可变步骤快照。`head == NULL` 不成立和循环退出时显示红色；完成后清除高亮。
- `tail->next = s` 更新原尾节点的 next，`tail = s` 才移动 tail 本身。新节点依次经历分配空节点、读值、初始化 next、接入和归位。
- 教学 C 代码使用类型别名、标准头文件和函数包裹，并检查 scanf 返回值、数值范围和 malloc 失败，失败时清理已分配节点。动画只演示正常输入、分配成功路径，不执行 C 或用户代码。scanf 本身按空白读取，网页两行格式校验更严格；教学函数不是通用文本解析器。
- 此示例没有头结点；head 是首个数据节点的指针。函数返回的链表使用结束后应由调用方释放。其他 C/C++ 示例仍是带头结点版本，未接入动画。
